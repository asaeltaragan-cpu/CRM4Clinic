# מקור לידים אמיתי — קליניקות אסתטיקה בישראל (Apify)

## מה זה

[aesthetic-clinics-israel.csv](aesthetic-clinics-israel.csv) — **100 עסקים אמיתיים** בתחום הטיפולים האסתטיים והקוסמטיקה בישראל, שנשלפו מ-Google Maps באמצעות Apify. זהו מידע עסקי ציבורי בלבד (שם עסק, טלפון, אתר, כתובת, דירוג) — **לא** מידע אישי של מטופלים.

| שדה | תיאור |
|---|---|
| שם_עסק | שם הקליניקה/העסק |
| קטגוריה | הקטגוריה כפי שמוגדרת ב-Google Maps |
| טלפון | מספר טלפון (E.164) |
| אתר | אתר האינטרנט, אם קיים |
| עיר / רחוב / מיקוד | כתובת |
| דירוג / מספר_ביקורות | דירוג Google Maps |
| מונח_חיפוש | איזו שאילתה החזירה את העסק הזה |
| קישור_Google_Maps | קישור ישיר לעמוד העסק |

**כיסוי:** 96/100 עם טלפון, 72/100 עם אתר.

## רענון הרשימה

להרצה חוזרת (למשל להרחיב לערים/מונחי חיפוש נוספים), קרא ל-Actor `compass/google-maps-extractor` דרך Apify Console/API עם אותו input, או פנה לסוכן Claude עם: "רענן את רשימת הלידים ב-CRM/leads עם [מונחי חיפוש/אזור נוספים]".

## חיבור כ-LeadSource אמיתי במערכת

הרשימה הזו היא Proof of Concept ל"מקור ליד אמיתי" (ראו `LeadSource` ב-[DATA_MODEL.md](../DATA_MODEL.md)). לחיבור מלא ואוטומטי:

1. **Apify Scheduler** — הגדרת הרצה תקופתית (שבועית/חודשית) של אותו Actor ב-Apify Console.
2. **Webhook** — Apify תומך ב-Webhook שמופעל כשה-run מסתיים (`ACTOR.RUN.SUCCEEDED`), עם payload שמכיל `datasetId`.
3. **Endpoint מקבל** — פונקציית שרת קטנה (Edge Function ב-Supabase, למשל) שמאזינה ל-Webhook, קוראת את ה-dataset מ-Apify API, וממפה כל שורה ל-`POST /public/leads` (ראו [API.md](../API.md)) עם `source = "Google Maps"`.
4. **מניעת כפילויות** — שימוש בשדה `phone` הייחודי per-clinic שכבר מוגדר בסכמה (`unique (clinic_id, phone)`) כדי שהרצות חוזרות לא ייצרו לידים כפולים.

## שימוש מומלץ בפועל

- **B2B**: רשימת פרוספקטים אמיתית למכירת CRM4Clinic לקליניקות (טלפון + אתר + דירוג נותנים תמונה איזה עסק פעיל ורציני).
- **הדגמה**: ייבוא לדמו (`CRM/demo`) כדוגמה למקור ליד אמיתי, לצד המקורות הקיימים (Instagram/Facebook/Google Ads/הפניות).

## הערות פרטיות ואתיקה

- כל הנתונים כאן הם **מידע עסקי ציבורי** (שמות עסקים, לא אנשים פרטיים) שכל אחד יכול לראות ב-Google Maps.
- **לא** נאסף כאן מידע על מטופלים/צרכנים פרטיים, ולא ייאסף — זה יהיה בעייתי מבחינת פרטיות ורגישות מידע רפואי.
- לפני פנייה שיווקית לעסקים ברשימה: לוודא עמידה בחוק התקשורת (תיקון 40, "חוק הספאם") אם משתמשים ב-SMS/מייל/פקס לפרסומת.
