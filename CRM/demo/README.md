# Clinic Revenue OS — דמו מכירה

דמו סטטי (HTML/CSS/JS, ללא build ושלא תלוי בשרת) המדגים מסך-מסך את מערכת ה-MVP, עם נתוני דוגמה קבועים וסיור מודרך קצר למכירה מול קליניקות.

## הרצה

פתיחה ישירה של [index.html](index.html) בדפדפן עובדת, אך מומלץ להריץ משרת סטטי מקומי כדי למנוע מגבלות `file://` בדפדפנים מסוימים:

```bash
cd CRM/demo
python -m http.server 8080
# ואז לפתוח http://localhost:8080
```

## מה בפנים

- **`data.js`** — מחולל נתוני דוגמה עם seed קבוע (אותו סיפור בכל טעינה): 50 לידים, 20 לקוחות, 5 אנשי צוות, 3 סוגי טיפולים, 4 מקורות ליד, משימות, פגישות והצעות טיפול הנגזרות מהם.
- **`index.html` / `app.js` / `styles.css`** — 6 מסכים אינטראקטיביים: דשבורד, לידים (Kanban+טבלה), כרטיס ליד/לקוחה, משימות ופולואפ, יומן, הכנסות והמרות, והגדרות — לפי [SITEMAP.md](../SITEMAP.md) ו-[WIREFRAMES.md](../WIREFRAMES.md).
- **`tour.js`** — סיור מודרך בן 9 שלבים ("🎯 סיור מודרך למכירה" בסרגל הצד) שעובר בין המסכים עם טקסט מכירתי שנשאב מהנתונים בזמן אמת (לא טקסט קבוע), ומסתיים במשפט הסגירה ממסמך האפיון.

## מגבלות מכוונות (דמו, לא המוצר)

כל הנתונים בזיכרון הדפדפן בלבד (ללא שרת/DB אמיתיים); פעולות כמו "קביעת ייעוץ" או "שינוי שלב" מוצגות כ-Toast בלבד; "סמן טופל / דחה / לא רלוונטי" במשימות ו-Kanban כן משנים את המצב בזיכרון לצורך תחושת אינטראקטיביות. מיועד להצגה מודרכת מול לקוח, לא לשימוש production.
